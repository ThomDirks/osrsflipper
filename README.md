# OSRS GE Flipper – Windows download

Windows desktop version of OSRS GE Flipper. Download **OSRS GE Flipper.exe** from this branch (click the file, then the download button) and double-click it: no Node.js or install needed. It runs in your browser at `http://127.0.0.1:47813` and sits in the system tray (right-click the coin to quit).

**New in this version**
- No Wordle request limiter, no git self-update
- **Decanting:** buy one dose, decant for free, sell another. Ranked routes after GE tax, a calculator, a side-by-side comparison with per-dose price history, and logging to Flip History
- **Technical indicators** on the item chart: SMA 20/50, EMA 20, Bollinger, RSI, MACD, Stochastic, OBV
- **Flip Speed:** instant-buys vs instant-sells and fill times per item
- **Price alerts on items you hold:** expected sale price per trade, alerts for big rises, drops, sudden moves and losses (bell menu, sound, desktop notifications)
- **Grey** and **Grey light** themes next to light and dark

Windows may show "Windows protected your PC" because the exe isn't code-signed. Click *More info* → *Run anyway*.
